# Savage Excuse Generator 🕶️

Savage Excuse Generator is a fun and interactive Android application designed to provide witty, relatable, and "savage" excuses for various life situations. Whether you're dodging a school assignment, a work meeting, or just being "mentally unavailable" for a relationship chat, this app has you covered.

## 🚀 Features

*   **Four Unique Categories**:
    *   **School**: For when your dog (or laptop) eats your homework.
    *   **Work**: Professional-ish excuses for the modern workplace.
    *   **Relationships**: Witty replies for "seen" messages and late responses.
    *   **Savage Mode**: High-attitude excuses for when you just don't care.
*   **Interactive UI**: Smooth category switching with visual feedback.
*   **One-Tap Generation**: Randomly generates a new excuse within the selected category.
*   **Copy to Clipboard**: Quickly copy your favorite excuse to paste anywhere.
*   **Social Sharing**: Share excuses directly to your friends via WhatsApp, Telegram, or any other messaging app.
*   **Fluid Animations**: Subtle scale and alpha animations for a polished user experience.

## 🛠️ Tech Stack

*   **Language**: [Kotlin](https://kotlinlang.org/)
*   **UI Framework**: [XML Layouts](https://developer.android.com/guide/topics/ui/declaring-layout) with [Material Components](https://material.io/develop/android)
*   **Architecture**: [View Binding](https://developer.android.com/topic/libraries/view-binding)
*   **Minimum SDK**: API 24 (Android 7.0)
*   **Target SDK**: API 36

## 📂 Project Structure

*   `MainActivity.kt`: Contains the core logic for category management, excuse generation, and UI interactions.
*   `activity_main.xml`: Defines the responsive layout using `ConstraintLayout`.
*   `build.gradle`: Project configuration, including dependencies for Material Design and AndroidX libraries.

## 📸 How to Use

1.  Open the app.
2.  Select a category from the top (School, Work, Relationships, or Savage).
3.  Tap the **Generate** button.
4.  Use the **Copy** 📋 or **Share** 📤 buttons to use the excuse!
